# Font Awesome vector icons

Icons used in Koteka Workspace are vector outlines based on **Font Awesome Free 4.7.0**, distributed under the **SIL Open Font License 1.1**. No webfont or font binary is bundled with this project. These outlines are included in `fa-icons.js` for offline-capable navigation.
